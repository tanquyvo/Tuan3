## Mục tiêu
Thư mục này tổng hợp ba bài thực hành JavaScript: nền tảng ngôn ngữ, thao tác DOM và sự kiện, và thư viện jQuery. Trang `index.html` đóng vai trò portfolio cá nhân, giới thiệu thông tin sinh viên, hành trình học tập, kỹ năng đạt được và liên kết đến từng Lab.

## Nội dung các Lab
### Lab 08 – JavaScript 1: Language Foundations
Thực hành cách liên kết JavaScript với HTML, cú pháp cơ bản, biến, hàm và sự kiện. Trang điều hướng bài tập: [Lab 08](Lab08/exercise.html).

### Lab 09 – JavaScript 2: DOM and Events
Thực hành truy cập/cập nhật DOM, event listeners và tương tác với biểu mẫu. Trang điều hướng: [Lab 09](Lab09/index.html).

### Lab 10 – JavaScript 3: jQuery
Thực hành jQuery selectors, thao tác DOM, events, effects và yêu cầu GET bất đồng bộ. Trang điều hướng: [Lab 10](Lab10/index.html).

## Cách xem
1. Mở `index.html` để xem portfolio.
2. Chọn một trong ba thẻ Lab để vào trang bài tập tương ứng.
3. Trong trang Lab 09 hoặc Lab 10, chọn Exercise muốn xem. Lab 08 sử dụng trang điều hướng `exercise.html` có sẵn.
