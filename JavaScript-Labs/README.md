## Nội dung các Lab

### Lab 08 – JavaScript 1: Language Foundations
Thực hành cách tích hợp JavaScript vào HTML bằng mã nhúng và tệp bên ngoài; kiểm tra trạng thái JavaScript và sử dụng thẻ `noscript`. Em cũng làm quen với Browser Console, các đối tượng String, Date và Math, cách tạo và thao tác với Array, Functions, Objects và Arrays of Objects.

**Trang điều hướng:** [Mở Lab 08](Lab08/index.html).

### Lab 09 – JavaScript 2: DOM and Events
Thực hành lựa chọn phần tử HTML, tìm hiểu quan hệ giữa các node trong DOM, tạo và xóa phần tử. Các bài tiếp theo tập trung vào xử lý sự kiện, thời điểm tải trang, gỡ lỗi bằng Debugger, làm việc với sự kiện focus/blur trên Form và kiểm tra dữ liệu đầu vào.

**Trang điều hướng:** [Mở Lab 09](Lab09/index.html).

### Lab 10 – JavaScript 3: jQuery
Thực hành thiết lập thư viện jQuery; sử dụng basic selectors và advanced selectors; đăng ký, thay đổi listener; chèn phần tử DOM; tạo hiệu ứng hiển thị, animation đơn giản và phức tạp. Cuối cùng, em gửi GET Request và sử dụng các callback của jqXHR như `done()`, `fail()` và `always()` để xử lý kết quả.

**Trang điều hướng:** [Mở Lab 10](Lab10/index.html).
