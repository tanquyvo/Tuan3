## Giới thiệu

Repository này lưu trữ các bài thực hành trong **Buổi 3** của học phần *Phát triển ứng dụng WEB/TMĐT*. Nội dung tập trung vào việc sử dụng HTML và CSS để định dạng văn bản, xây dựng thanh điều hướng, tạo bố cục trang web, trình bày portfolio, sử dụng hình ảnh, hiệu ứng hover và tích hợp thư viện icon Font Awesome.

Trang `index.html` là portfolio cá nhân kiêm trang điều hướng, giúp truy cập các bài thực hành và thông tin liên hệ.

## Công nghệ và tài nguyên sử dụng

- **HTML5:** xây dựng cấu trúc nội dung trang.
- **CSS3:** định dạng văn bản, màu sắc, khoảng cách, border, background, bố cục, responsive và hiệu ứng hover.
- **CSS Grid / Inline-block / Position:** sử dụng trong các bài thực hành bố cục.
- **Font Awesome 5.15.4:** cung cấp icon cho portfolio và các bài có tích hợp biểu tượng.
- **Animate.css 3.7.2:** được liên kết trong Bài 8a.
- **Google Fonts:** được sử dụng trong portfolio để hiển thị typography.
- **Hình ảnh minh họa:** lưu trong các thư mục `imgs/` hoặc cạnh file HTML tương ứng.

Một số tài nguyên được tải từ CDN hoặc website bên ngoài. Vì vậy, cần kết nối Internet để hiển thị đầy đủ icon, font và hình ảnh trực tuyến.

## Cách xem bài trên máy tính

### Cách 1: Mở trực tiếp

1. Tải repository về máy hoặc mở thư mục `VeNha` bằng VS Code.
2. Mở file `index.html` bằng trình duyệt.
3. Chọn bài tập muốn xem trong khu vực danh sách bài tập.

### Cách 2: Sử dụng VS Code Live Server

1. Mở thư mục `VeNha` bằng Visual Studio Code.
2. Cài extension **Live Server** nếu chưa có.
3. Nhấn chuột phải vào `index.html`.
4. Chọn **Open with Live Server**.
5. Nhấn các liên kết trong portfolio để mở từng bài.
